# T04 間違えた問題だけを解き直すモード

- 優先度: 中
- 状態: ✅ 完了

## 背景

間違えた回数は画像ごとの数字（`imageStats.wrongCount`）として次の出題に効くだけで、
間違えた問題そのものを解き直す流れがない。

## やること

- 結果画面に「まちがえた問題をもう一度」ボタンを置く（間違いが1問以上のとき）。
- 押すと、間違えた問題だけを、選択肢の並びを変えて出し直す（AIを呼ばないのですぐ始まる）。
- 解き直しでは、10問固定の前提（`TOTAL_QUESTIONS`）に頼らず、出す問題の数で進み具合・結果を出す。
- 解き直しの結果は画像ごとの統計を二重に数えない。

## 完了条件

- 間違えた問題だけで1回遊べて、結果画面まで行ける。
- 全問正解のときはボタンが出ない。

## 経過

### 2026-11-21

- 結果画面に「まちがえた○問をとき直す」ボタンを置いた（まちがいが1問以上のときだけ）。押すと、まちがえた問題だけを選択肢の並びを変えて出し直す。AI は呼ばないので、すぐ始まる。
- 解き直し中は問題画面の右上に「ふくしゅう」と出る。結果画面の見出しは「ふくしゅうのけっか」。
- 問題数を `TOTAL_QUESTIONS`（10）に決め打ちしていた所を、出している問題の数で数えるようにした（進み具合・結果・励ましの言葉）。
- 解き直しでは、画像ごとの統計（まちがえた回数）を変えない。ランプからのやり直しでも同じ。
- `QuizResult` に、えらんだ答え `chosenIndex` を残すようにした（解説画面・ふりかえり・きろくで使う）。
- 実際にクイズを作り、7問まちがえてから「とき直す」を押すと、7問の解き直しが始まることを確認した。
- あわせて変えたこと: 「やめる」「おわる」でタイトルに戻ったとき、えらんだ写真と設定を残すようにした（同じ写真ですぐまた遊べる。以前は全部消えていた）。
