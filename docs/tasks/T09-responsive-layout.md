# T09 画面サイズ・解像度に合わせた表示

- 優先度: 高
- 状態: ✅ 完了（残りは [引継ぎ資料](../handover.md) にまとめた）

## 背景

[ui-audit.md](../ui-audit.md) の A1〜A9。文字の大きさが横幅だけで決まっていて、背の低い画面であふれる。
スマホではスタートボタンが画面の外、結果画面はスクロールできない、など。

## やること

- 文字の大きさを `clamp()` と `min(vw, vh)` で連続的に変える仕組みを Tailwind の設定に用意し、画面ごとに使う。
- 高さは `100dvh`、端は safe-area の余白を取る。
- タイトル画面: スマホでは「はじめる」を画面下に固定して常に見えるようにする。横長で背の低い画面では設定と写真を横に並べる。
- 問題画面: 問題文と選択肢が1画面に収まるようにし、長い選択肢でも最小 14px を守る。
- 結果画面: スマホ縦ではスクロールできるようにし、ボタンが必ず押せるようにする。
- 確認する画面サイズ: 375×667、375×812、812×375、768×1024、1024×768、1366×768、1920×1080、2560×1440。

## 完了条件

- 上の各サイズで、どの画面でも主なボタンと問題文・選択肢が見えて押せる（スクリーンショットで確認）。

## 経過

### 2026-11-21

- [tailwind.config.js](../../tailwind.config.js) に、画面の「横幅と高さの小さい方」(vmin) で連続的に変わる文字の大きさ `text-fl-*` と余白 `p-fl-*` を用意した。最小値は本文16px・補足13px（選択肢は最小14px）。`sm:`/`lg:` で段階的に変えるのはやめた。
- 背の低い画面用に `short:`（高さ540px以下）を追加。スマホ横向きでは「問題と選択肢」「設定と写真」「結果と振り返り」を横に並べる。
- 高さは `100dvh`、端は `env(safe-area-inset-*)` で余白を取る（`.safe-area`）。`viewport-fit=cover` を指定。
- タイトル画面: 「はじめる」を画面の下に固定し、どの大きさでも見えるようにした。
- 問題画面: 問題文・選択肢とも長さで大きさを変え、1画面に収める。大きい画面では最大幅を 1600px にした。
- 結果画面: スクロールできるようにし、ボタンが必ず押せるようにした（以前は `overflow-hidden` で切れていた）。
- 実際にクイズを作って遊び、次のサイズで確かめた。
