# T05 学習の記録を残す

- 優先度: 中
- 状態: ✅ 完了

## 背景

点数・間違えた問題は画面を閉じると消える。続けて使う理由がない。

## やること

- 1回遊ぶごとに、日時・モード・先生・点数・間違えた問題（問題文・正解・解説）をブラウザに保存する（localStorage。容量に余裕を持たせ、古いものから消す）。
- タイトル画面から「きろく」を開けるようにし、最近の点数の推移（グラフ）と、間違えた問題の一覧を見られるようにする。
- 記録を全部消すボタン（確認つき）を置く。

## 完了条件

- 遊んだあと画面を読み込み直しても記録が残っている。
- 保存に失敗しても（プライベートブラウズなど）ゲームは止まらない。
