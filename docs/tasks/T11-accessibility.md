# T11 使いやすさ・アクセシビリティ

- 優先度: 中
- 状態: ✅ 完了（残りは [引継ぎ資料](../handover.md) にまとめた）

## 背景

[ui-audit.md](../ui-audit.md) の C1〜C7。

## やること

- アイコンだけのボタンに `aria-label` を付ける（×ボタン、進み具合のランプ）。
- 問題画面で 1〜4 / A〜D キーで答え、解説画面で Enter で次へ進めるようにする。
- フォーカス枠（`focus-visible`）を見えるようにする。
- ダイアログは Esc で閉じ、`role="dialog"` と `aria-modal` を付ける。
- 問題文・解説は文字を選択できるようにする（ボタンは選択不可のまま）。
- 進み具合のランプを押しやすい大きさ（タップ領域 32px 以上）にする。
- `prefers-reduced-motion` のときはアニメーションを止める。

## 完了条件

- キーボードだけで1回遊べる。
- ×ボタンなどが読み上げで名前つきになる。

## 経過

### 2026-11-21

- アイコンだけのボタンに名前を付けた（×ボタンは「とじる」、ランプは「第3問 まちがい。押すとこの問題からやり直す」など）。
- キーボード操作: 問題画面は 1〜4 / A〜D で回答できる。解説画面は「つぎの問題へ」に最初からフォーカスがあるので、Enter で進める。キーボードだけで1回遊べることを確認した。
- フォーカス枠（黄色の外枠）を `:focus-visible` で表示する。
- [components/Dialog.tsx](../../components/Dialog.tsx) に次を入れた: `role="dialog"`・`aria-modal`・見出しとの関連付け、Esc で閉じる（動作確認済み）、Tab がダイアログの外に出ない、閉じたら元の場所にフォーカスを戻す。
- 問題文・解説・ふりかえりは文字を選択できるようにした（ボタンは選択不可のまま）。以前は画面全体が選択できなかった。
- 進み具合のランプは、見た目は小さいまま押せる範囲を 24〜32px 角に広げた。
- `prefers-reduced-motion` のときはアニメーションを止める。
- 正解・不正解・問題番号の変化を `aria-live` で読み上げる。
- 残り: 実際の読み上げソフト（VoiceOver / NVDA）での確認はしていない。
