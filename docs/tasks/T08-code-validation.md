# T08 ルールで弾けるものはコードで弾く

- 優先度: 中
- 状態: ✅ 完了

## 背景

プロンプトで禁止している内容のうち、機械的に見つけられるものは AI の見落としに頼らずコードで確実に落としたい。
`services/quizValidation.ts` ですでに一部（教材を指す言葉・正解の照合など）はやっている。

## やること

- 今の検証内容を確認し、足りないものを足す。候補:
  - 選択肢の中に、空白・かっこ・全角半角の違いだけの重複がないか
  - 選択肢の中に、問題文の言葉をそのまま含む「答えが問題文に書いてある」ものがないか（正解だけが問題文の語を含むなど）
  - 正解の選択肢だけ極端に長い・ふりがながついている
  - 同じ問題文（ほぼ同じ）が2問ないか
- テストを足す。

## 完了条件

- 追加した検証ごとにテストがあり、`npm test` が通る。

## 経過

### 2026-11-21

- 今ある検証を確認: 形の確認、選択肢の重複（空白・全角半角のゆれ込み）、教材を指す言葉、あまの先生の丸写し、正解と選択肢が同じ重複問題、`answer` と選択肢の照合はすでにあった。
- [quizValidation.ts](../../services/quizValidation.ts) に追加:
  - `revealsAnswer`: 選択肢の見た目から正解が分かる問題を捨てる。正しい問題を捨てすぎないよう、はっきりしたものだけ。
    - 正解にだけ（ふりがな・注釈）が付いている
    - 正解だけが極端に長い（ほかのどれよりも2倍以上、かつ10文字以上長い）
    - 正解の言葉（2文字以上）が問題文にそのまま書いてあり、不正解の言葉は書いていない
  - 問題文が同じ（空白・かっこ・句読点のちがいだけ）問題は1つだけ残す。
- テストを5件追加（合計80件、すべて成功）。
- 気をつけること: AI には12問作らせて10問使うので、捨てる問題が増えると作り直し（待ち時間）が増える。T03 の評価で、捨てた数も記録して様子を見る。
