# T10 見やすさ・デザインの見直し

- 優先度: 中
- 状態: ✅ 完了（残りは [引継ぎ資料](../handover.md) にまとめた）

## 背景

[ui-audit.md](../ui-audit.md) の B1〜B7。コントラスト不足、英語の飾り文字、装飾の多さ、
結果画面の「PERFECT CLEAR!」が点数と関係なく出る不具合など。

## やること

- 色を役割ごと（背景・文字・強調・正解・不正解）に Tailwind の設定にまとめる。白い文字を置く背景は濃いめにして、コントラスト比 4.5:1 以上にする。
- 英語の飾り文字（CONFIG・GAME MODE・Victory Dashboard など）を日本語の短い見出しにするか消す。
- 結果画面の見出し・グレードを点数に合わせる（不具合の修正）。
- 正解したときは「くわしい解説」ボタンを出さない（灰色の押せないボタンをやめる）。
- 枠の太さ・角丸・影の段階をそろえ、装飾（回転するキラキラ・大きなぼかし）を減らす。

## 完了条件

- 主な文字のコントラスト比が 4.5:1 以上。
- 結果画面の見出しが点数に合っている。

## 経過

### 2026-11-21

- 色を役割ごとに [tailwind.config.js](../../tailwind.config.js) にまとめた。
  - `brand`: 背景（sky-700 → indigo-700）。白文字で 5.9:1 以上。以前の明るい水色（#4facfe→#00f2fe）に白文字は 2:1 前後で読みにくかった。
  - `ink`: 白地の本文（slate-800）と補足（slate-600）。
  - `ok`: 正解（teal-700。白文字 5.5:1）。`ng`: 不正解（rose-700。白文字 6.4:1）。
  - いちばん押してほしいボタンは「黄色地に黒文字」にした（以前のオレンジ地に白文字は 2.8:1）。
- 英語の飾り文字（CONFIG・GAME MODE・Victory Dashboard・Accuracy・GOD など）をやめ、日本語の見出し（1. あそびかた／2. 先生／3. 写真、けっか、ふりかえり）にした。
- **不具合修正**: 結果画面に点数と関係なく「PERFECT CLEAR!」と出ていた。点数に合わせた見出し（パーフェクト！／すごい！／よくがんばったね／つぎはもっといけるよ）にし、グレード（GOD/MASTER/GOOD）はやめた。
- 正解したときは「くわしい解説」ボタンを出さないようにした。不正解のときは「あなたのこたえ」も出す。
- 枠の太さ・角丸（`rounded-card` / `rounded-btn`）・影をそろえた。回転するキラキラ・大きなぼかし・`backdrop-blur` はなくした（古いタブレットで重くなる原因）。
- 結果画面に「ふりかえり」（1問ずつの ◯✕・こたえ・えらんだ答え）を追加。
- AI の解説に混ざる `**太字**` の記号が、そのまま表示されていた。記号を見せずに太字で表示するようにした。
- 残り: 白文字を `text-white/85` のように少し薄くしている所は、背景の明るい側（sky-700）で 4.5:1 前後。気になるなら `text-white` にそろえる。

### 2026-11-21（2回目: もう少しポップに）

使ってみての感想「色が地味になった」「正解・不正解の色がうすい」を受けて見直した。

- 背景を、あざやかな「青 → むらさき → ピンク」のグラデーションにし、半透明の水玉を重ねた（`.pop-bg`。CSS だけで描くので、どの解像度でもくっきりで、読み込みも増えない）。白い文字はどの色の上でも 4.5:1 以上。
- 選択肢の A〜D マークを、1つずつ違う色（赤・青・緑・オレンジ）にした。
- 答えたあとの選択肢:
  - 正解はあざやかな緑（green-600）＋明るい緑のふち＋白い丸に ◯、ぽんっとはずむ。
  - えらんだ不正解はあざやかな赤（rose-600）＋明るい赤のふち＋白い丸に ✕、左右にゆれる。
  - それ以外の選択肢は薄くして、正解・不正解が目立つようにした。
  - 色が少しずつ変わる動き（transition）をやめ、すぐ切り替わるようにした（切り替わる途中が薄く見えていたため）。
- 解説画面: 背景を緑〜青緑（正解）／赤〜むらさき（不正解）に水玉を重ねた。カードの上に色の帯と大きな ◯／✕ を置き、「あなたのこたえ」「せいかい」「かいせつ」に色の線を付けた。
- タイトルの「AI」を黄色に、結果の点数をむらさきにした。
- 白地の小さな文字で正解・不正解の色を使う所（ふりかえり・きろく）は、読みやすい濃い色（`ok-ink` / `ng-ink`）を使う。
- 確認: スマホ縦（375×812）とノートPC（1366×768）で、タイトル・問題（答える前／答えたあと）・解説・結果を画面で確かめた。スマホでは「きろく」ボタンが2行に折れていたので1行に直した。
