# UI・デザイン・画面サイズの洗い出し（2026-11-21）

スマホ縦（375×812）・スマホ横（812×375）・ノートPC（1366×768）で画面を表示し、
[App.tsx](../App.tsx) と [components/](../components/) のコードを読んで洗い出した。

## A. 画面サイズ・解像度への対応

| # | 問題 | どこ | 影響 |
| --- | --- | --- | --- |
| A1 | 文字の大きさが**横幅だけ**で決まっている（`sm:` `lg:`）。高さを見ていないので、横長で背の低い画面（ノートPC 1366×768、スマホ横）で `lg:text-6xl`〜`text-8xl` が縦にあふれる | 問題文・正解表示・結果画面・生成中の文言 | 問題文や選択肢がスクロールしないと見えない |
| A2 | 画面の高さに `h-full`（= 100%）を使っている。スマホのブラウザはアドレスバーの出し入れで高さが変わり、下が切れる | `index.css` の `body`/`#root` | 「はじめる」「つぎの問題へ」が隠れることがある |
| A3 | iPhone のノッチ・ホームバーの安全領域（safe-area）を考えていない | 全画面 | 端のボタン・表示が欠ける |
| A4 | スマホ縦でタイトル画面の「はじめる」ボタンが画面の外（下までスクロールが必要） | タイトル画面 | 何をすればいいか分かりにくい |
| A5 | スマホ横では設定欄が画面いっぱいになり、写真の追加・スタートが見えない | タイトル画面 | 同上 |
| A6 | 1366×768 で「はじめる!」が2行に折れる（`min-w-[450px]` と `px-40` の組み合わせ） | タイトル画面 | 見た目が崩れる |
| A7 | 結果画面は `overflow-hidden` で、スマホ縦だとアドバイス欄やボタンが切れて**スクロールもできない**（コードから推定） | 結果画面 | 「もういちど」「おわる」が押せない恐れ |
| A8 | 長い選択肢は `text-[10px]` まで小さくなる | 問題画面 | 子どもには読めない |
| A9 | `user-scalable=no` で拡大できない | `index.html` | 小さい字を拡大して読めない |

## B. 見やすさ・デザイン

| # | 問題 | どこ |
| --- | --- | --- |
| B1 | 明るい水色の背景（`#4facfe→#00f2fe`）に白い文字・半透明（`opacity-40` など）の文字で、**文字と背景の差（コントラスト）が足りない** | タイトル画面の見出し・ラベル、「MAX 50」など |
| B2 | 「CONFIG」「GAME MODE」「Victory Dashboard」「Accuracy」など**英語の小さな飾り文字**が多い。子ども向けなのに読めない・意味がない | 各画面 |
| B3 | 結果画面に、点数に関係なく **「PERFECT CLEAR!」** と出る。グレードも0点で「GOOD」 | 結果画面（不具合） |
| B4 | 枠線8〜16px・角丸5rem・影・ぼかし・回転するキラキラなど装飾が多く、どこが大事か分かりにくい。画面ごとに色づかいもばらばら | 全画面 |
| B5 | 正解したときも「くわしい解説を見る」ボタンが灰色で残り「（せいかいの人は押せません）」と出る。押せないボタンは混乱のもと | 解説画面 |
| B6 | 生成中の画面がぐるぐるだけで、どのくらいかかるか・何をしているかが伝わりにくい | 生成中画面 |
| B7 | `backdrop-blur` を多用していて、古い・安いタブレットで動きが重くなりやすい | 全画面 |

## C. 使いやすさ・アクセシビリティ

| # | 問題 | どこ |
| --- | --- | --- |
| C1 | ×ボタン・進み具合のランプなどに読み上げ用の名前（`aria-label`）がない | Modal・解説ダイアログ・ProgressBar |
| C2 | キーボードで答えられない（1〜4 / A〜D キー）。PC で遊ぶときに不便 | 問題画面 |
| C3 | フォーカスしている場所が見えない（フォーカス枠の指定なし） | 全ボタン |
| C4 | ダイアログが開いても Esc で閉じられず、裏の画面にフォーカスが移る | Modal・やめる確認・解説 |
| C5 | 画面全体が `select-none` で、問題文や解説をコピーできない | 全画面 |
| C6 | 進み具合のランプが小さく（14px）、指で押しにくい | 問題画面 |
| C7 | 動きを減らす設定（`prefers-reduced-motion`）を考えていない | アニメーション全般 |

## 対策の方針

- **文字の大きさは `clamp()` で、横幅と高さの小さい方に合わせて連続的に変える**（`min(vw, vh)` を使う）。`sm:`/`lg:` の段階切り替えをやめる。
- 画面の高さは `100dvh`、端は `env(safe-area-inset-*)` で余白を取る。
- 背の低い画面（`max-height: 500px` など）用の配置を用意する（横並び・装飾を省く）。
- 色は「背景・文字・強調・正解・不正解」の役割ごとに Tailwind の設定にまとめ、コントラスト比 4.5:1 以上を守る。
- 英語の飾り文字はやめ、日本語の短い見出しにする。
