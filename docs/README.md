# ドキュメント

このフォルダには、アプリの設計・課題・作業の経過をまとめます。

| 場所 | 中身 |
| --- | --- |
| [tasks/](tasks/README.md) | 改善タスクの一覧と、タスクごとの経過記録 |
| [ui-audit.md](ui-audit.md) | UI・デザイン・画面サイズまわりの問題点の洗い出し |
| [deploy.md](deploy.md) | 動かし方・公開のしかた（APIキーの置き場所など） |
| [superpowers/](superpowers/) | 過去の設計書・実装計画（50枚対応＋重み付きサンプリング） |

## 書き方のルール

- タスクは `tasks/Txx-なまえ.md` に1つずつ書く。
- 作業したら、そのタスクの「経過」に日付つきで追記する（何をしたか・わかったこと・残ったこと）。
- 状態が変わったら [tasks/README.md](tasks/README.md) の一覧表も合わせて直す。
