## Gemini API の無料枠

### 公式の情報（[rate-limits のページ](https://aistudio.google.com/docs/rate-limits)、2026-11-23 に確認）

- 上限は **APIキーごとではなく、プロジェクトごと**にかかる。キーを増やしても枠は増えない。
- 1日の回数（RPD）は **太平洋時間の0時**に戻る（日本時間では、冬時間なら17時、夏時間なら16時）。
- モデルごとの数字（1分あたり・1日あたりの回数）は**公開のドキュメントには載っていない**。AI Studio にログインして [レート制限のページ](https://aistudio.google.com/rate-limit) で見る必要がある。
- **Pro のモデル（Gemini 3.1 Pro Preview など）が無料枠で使えるか、使えるなら1日何回かは、ドキュメントからは確かめられなかった。** 上のページで確認すること（未確認）。アプリと評価は今のところ Pro を使っていない。

## 今わかっている問題点

### すなお先生（最優先）

**基準の数字**（直す前。全34まい・作問 gemini-3.5-flash-lite・採点 gemini-3.5-flash・3回）: 出題10問のすべて合格 87%、answerCorrect 93%、uniqueAnswer 97%、naturalJapanese 87%、答え合わせ後に使える問題 11.7/12。

2026-11-22〜23 の評価（[eval/results/](../eval/results/)、git には入れていない）で見つかった、出題された問題の不合格の型:

1. **問いの形と選択肢の形がかみ合わない**（いちばん多い）
   - 「1853年に来航した人物の名前を**漢字で書くと**どれ？」→ 選択肢がペリー・コロンブスなどカタカナ。問い方の割り当て【書き】を、漢字ではない題材にも当てはめている。
   - 「『うたが』に続く**送りがな**はどれ？」→ 選択肢が「うたがう」と言葉全体になっている。
   - 答え合わせのAIは「中身として正しいか」だけを見て○にしてしまい、捨てられていない。
2. **問題文の前提がまちがい**
   - 「『えきちょう』の『えき』と同じ漢字を使う言葉」→ 駅長の「駅」と益虫の「益」はちがう字。正解の選択肢そのものは正しいので、答え合わせを通ってしまう。
3. **問題文の言葉が足りない・不自然**
   - 「2ひきとめだか6ひきを合わせる式」（何が2ひきか書いていない）、「『イブ』という意味を表す、大みそかを表す英語表現」。
4. **読みが2つある言葉の読みの問題**（あまの先生で出たが、すなお先生でも起こりうる）
   - 「利益（りえき／りやく）」「尊い（とうとい／たっとい）」で、不正解の選択肢に別の正しい読みが入る。尊いは答え合わせで捨てたが、利益は出題された。

### あまの先生・クイズモード

- あまの先生: 空欄の前後がなく、何を入れるか分からない「（　）に入る言葉」。答え合わせで捨てられている。
- クイズモード: 「漢字ドリルに載っている〜」は T13 で取り去るようにした。今回の評価では大きな問題は出ていない（優先度は低い）。

### 評価のしくみ

- 採点のAIも、まちがえることがある（例: わざと実在しない言葉にした不正解を「誤字」と数える）。数字は目安で、不合格の問題の中身を読んで判断する。
- 1回の評価で出題されるのは1モードあたり20問前後なので、1問で数％動く。比べるときは数周回してから。
- `eval/results/` は git に入れていない。文書から結果ファイルへのリンクは、そのPCでしか開けない。
